# Ripasso di matematica: trigonometria

Seno, coseno e tangente spiegati da zero, con esercizi guidati e una calcolatrice scientifica.

- `index.html`: pagina iniziale
- `ripasso-trigonometria.html`: il ripasso, in dodici tappe
- `calcolatrice.html`: la calcolatrice a tutto schermo

Si apre direttamente nel browser, anche dal telefono. I progressi restano salvati nel browser di chi apre la pagina.
